# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 3.x | Yes |
| < 3.0 | No |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub: <https://github.com/bayinformatics/croppie/security/advisories/new>

Include what you found, how to reproduce it (a minimal example helps), and the Croppie version and browser. You should get a first response within a few days. Once a fix is released, the advisory is published and you are credited if you wish.
