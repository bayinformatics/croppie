Keyboard controls and prototype limits

Focus the image and use arrow keys to pan, or + / − to zoom. Focus a crop handle and use arrow keys to resize or move it. Hold Shift for 10-pixel steps. Every control works with a keyboard.

Empty areas export as transparency. Export preserves the original image as its source, but uses one Canvas resampling pass. Large reductions can show aliasing in Firefox and Safari. This prototype has no undo history, metadata preservation, or guarantee that the image fills the crop.
